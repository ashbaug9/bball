7th Grade Basketball Practice - home screen app

PUT IT ONLINE (pick one)
A) Netlify Drop: go to app.netlify.com/drop, drag this whole folder onto the page, and copy the link it gives you. (Create a free account so the site doesn't expire.)
B) GitHub Pages: create a public repository, upload every file in this folder, then Settings > Pages > Deploy from branch (main, root). Your link is https://YOURNAME.github.io/REPO/

ADD TO A PHONE
iPhone: open the link in Safari > Share > Add to Home Screen.
Android: open the link in Chrome > menu (three dots) > Add to Home screen / Install app.

NOTES
- Works offline after the first open.
- Free throw logs, done marks, and video links save on each phone.
- To update the app later, replace index.html with the new version. Phones pick it up the next time they open it online.
